# Branching Video (mod_videobranch)

Branching Video is a Moodle activity module for interactive videos with decisions, alternate paths and multiple endings.

Teachers can add multiple videos, create decisions at specific timecodes, and route each option to another time in the
same video, another video, another decision, or a named ending. Paths may reconnect to the main flow. The activity
records every learner decision, supports resume, optionally permits changing earlier decisions, and can reveal the final
path to the learner.

Reports include learner decision histories, alternative distribution, most-used paths, abandonment points and reached
endings. Completion can be configured to occur when a valid ending is reached.

Supported video sources: uploaded video, direct media URL, YouTube and Vimeo.

## Requirements

Moodle 4.4 or newer.

## Installation

Copy the `videobranch` directory to `mod/videobranch` and visit Site administration > Notifications.
