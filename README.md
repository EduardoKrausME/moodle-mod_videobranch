# Branching Video (mod_videobranch)

Branching Video is a Moodle activity for interactive videos with decisions, alternate paths and multiple endings.

## How it works

Teachers add one or more videos and create decisions at specific timecodes. Each option can send the learner to another
time in the same video, another video, another decision or a named ending, and different paths can reconnect later.

The activity records each learner decision and can resume an unfinished path. Teachers can also decide whether learners
may change earlier choices and whether the final path is shown after completion.

## Video sources

- uploaded video;
- direct media URL;
- YouTube;
- Vimeo.

## Reports and completion

Reports show decision histories, option distribution, most-used paths, abandonment points and reached endings.
Completion can be tied to reaching a valid ending, which makes the activity suitable for scenarios, simulations,
case-based learning and consequence-driven training.
